# minpeter/homebrew-tap

```sh
brew install minpeter/tap/et-rs
```

| Formula | Description |
| --- | --- |
| `et-rs` | [et.rs](https://github.com/minpeter/et.rs) — single telemetry-free EternalTerminal binary (Rust port). Installs `et`, `etserver`, `etterminal`, `htm`, `htmd`. |

Formulas are updated automatically by the et.rs release pipeline.
